Política de Privacidade – Betania

Última atualização: 17 de novembro de 2025
Desenvolvido por: DamCode

1. Introdução

A sua privacidade é importante para nós. O aplicativo Betania, desenvolvido pela DamCode, tem como compromisso respeitar a privacidade dos usuários e cumprir as normas da Lei Geral de Proteção de Dados (LGPD – Lei nº 13.709/2018).

Esta Política descreve de forma clara como tratamos os dados dentro do aplicativo. Nosso objetivo é fornecer total transparência sobre o uso das informações.

2. Coleta de Dados

O aplicativo Betania não coleta, não solicita e não armazena nenhum dado pessoal identificável dos usuários.

Não realizamos:

  • Coleta de nome, e-mail, telefone ou documentos;
  • Cadastro ou login;
  • Armazenamento de histórico de palpites;
  • Armazenamento de comportamentos, preferências ou uso;
  • Rastreamento via cookies ou tecnologias semelhantes.

3. Uso das Informações

O aplicativo utiliza exclusivamente as informações fornecidas no próprio momento da interação, como seleções de times, palpites ou configurações temporárias. Esses dados:

  • São usados apenas para gerar análise de IA;
  • Não são enviados a servidores próprios do aplicativo;
  • Não são armazenados, salvos ou compartilhados.

A geração dos palpites é realizada através do Gemini (versão gratuita), uma inteligência artificial genérica que não é treinada especificamente para previsão esportiva.

4. Compartilhamento de Dados

O aplicativo não compartilha, vende ou cede dados a terceiros.

As informações digitadas pelo usuário no momento do palpite podem ser enviadas temporariamente à API do Gemini, única tecnologia externa utilizada para gerar respostas. Nenhuma informação enviada é armazenada ou reutilizada por nós.

5. Armazenamento e Segurança

Como o aplicativo não armazena dados pessoais, não existe banco de dados com informações identificáveis de usuários.

Todas as interações são processadas em tempo real e descartadas após o uso.

6. Direitos do Usuário

De acordo com a LGPD, você possui direitos relacionados ao tratamento de dados pessoais. Embora o aplicativo não armazene nenhuma informação identificável, reafirmamos que você pode:

  • Solicitar esclarecimentos sobre eventuais dados temporários processados em IA;
  • Solicitar informações sobre nossa política de não armazenamento;
  • Revogar permissões concedidas (caso use funcionalidades do sistema operacional).

7. Uso de Tecnologias de Terceiros

O aplicativo utiliza exclusivamente o serviço de IA da API Gemini. Ao usar essa tecnologia, o usuário concorda que a responsabilidade sobre o tratamento de dados da API do Gemini é da própria plataforma.

8. Alterações nesta Política

Podemos atualizar esta Política de Privacidade a qualquer momento para atender requisitos legais ou melhorias do aplicativo. A versão atualizada sempre estará disponível dentro do app.
